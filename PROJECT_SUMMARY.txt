🎯 PROJECT OVERVIEW
═══════════════════════════════════════════════════════════════════════════════

This is a complete, production-ready AWS Data Engineering project that:
✅ Ingests YouTube trending data from YouTube API v3
✅ Implements Medallion Architecture (Bronze → Silver → Gold layers)
✅ Automates ETL/ELT pipelines using AWS Glue
✅ Validates data quality before aggregation
✅ Orchestrates workflows with Step Functions
✅ Provides analytics-ready data in S3
✅ Enables querying with Amazon Athena
✅ Ready for visualization in QuickSight

🔧 QUICK START (15 minutes)
═══════════════════════════════════════════════════════════════════════════════

1. Store YouTube API Key:
   aws secretsmanager create-secret --name youtube-api-key --secret-string "YOUR-KEY"

2. Configure Terraform:
   cd terraform
   cp terraform.tfvars.example terraform.tfvars
   # Edit terraform.tfvars with your settings

3. Deploy:
   terraform init
   terraform plan
   terraform apply

4. Test Pipeline:
   aws stepfunctions start-execution \
     --state-machine-arn $(terraform output -raw stepfunctions_arn) \
     --input '{"region":"US","date":"2024-01-01"}'

5. Monitor:
   aws logs tail /aws/lambda/youtube-data-pipeline-prod-ingestion --follow
